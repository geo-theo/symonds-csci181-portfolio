SAR Ship Detection (YOLO)

Trained an object detection model to identify ships in Synthetic Aperture Radar imagery. The workflow includes image preprocessing, labeling, model training, and evaluation steps.

  • Prepared SAR imagery for object detection workflows.
  • Labeled ship features for supervised model training.
  • Evaluated model outputs against detection performance goals.

Kerala Snakebite Accessibility

Built an accessibility analysis to estimate travel time to hospitals and highlight higher-risk areas. The project combines land cover, roads, population, and healthcare access factors.

  • Modeled travel time to hospital access points.
  • Combined geographic risk factors into a spatial workflow.
  • Mapped underserved areas for clearer public health planning.

Paris Transit Desert Analysis

Mapped public transit access using GTFS data and isochrones to identify underserved neighborhoods. The project focuses on clear cartography and reproducible geospatial analysis.

  • Processed GTFS transit data for accessibility analysis.
  • Created isochrone-based maps of reachable transit service.
  • Identified neighborhoods with weaker transit coverage.
